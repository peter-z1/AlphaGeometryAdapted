# Generated teaching data

`auxiliary_v4/` is the complete deduplicated fine-tuning split used by the
selected reconstruction. The `.txt` files are model-ready strings; the
`.jsonl.gz` files retain prompt, target, and audit metadata. Counts are:

- train: 14,284
- validation: 790
- test: 677

`pretraining_sample/train.txt` is a deterministic first-2,000-line teaching
sample of the full 5,292,720-row v4 training split. It is suitable for parsing,
tokenizer, and tiny-model demonstrations, but not for recreating the selected
pretrained model.

The full pretraining train/validation/test files are distributed with the
large release bundle described by `release/manifest-v4.json`. The sample can
be regenerated with `scripts/make_teaching_sample.py`.

All files are synthetic symbolic strings generated by this project. See
`SYNTHETIC_DATA_PIPELINE.md` and `PROVENANCE.md` for construction, filtering,
and exact lineage.
